# GOD EYE SAE — Internacionalización (i18n)

## Arquitectura

El sistema de internacionalización está implementado de forma centralizada y ligera, sin dependencias externas adicionales.

### Estructura

```
src/i18n/
├── index.ts           # Función t(), tipos, utilidades
└── locales/
    ├── es-ES.ts       # Español (predeterminado)
    └── en-US.ts       # Inglés
```

### Uso

```typescript
import { t, Locale } from './i18n';

// Uso básico
const label = t('app.title', 'es-ES'); // "GOD EYE SAE"

// Con estado React
const [locale, setLocale] = useState<Locale>('es-ES');
const label = t('header.search', locale);
```

### Idiomas Soportados

| Código | Idioma | Estado |
|--------|--------|--------|
| es-ES | Español de España | Predeterminado, completo |
| en-US | Inglés (EE.UU.) | Secundario, completo |

### Convenciones

- Las claves siguen la estructura `sección.subsección.elemento`
- Los nombres propios se mantienen sin traducir: NASA, USGS, EFFIS, Copernicus, Sentinel, Landsat, Cesium, Esri, OpenStreetMap
- Cuando es necesario, se añade una descripción en el idioma activo

### Extensión

Para añadir un nuevo idioma:

1. Crear `src/i18n/locales/xx-XX.ts` con la misma estructura
2. Importarlo en `src/i18n/index.ts`
3. Añadirlo al tipo `Locale`
4. Añadirlo al selector de idioma en la cabecera

### Persistencia

El idioma seleccionado se almacena en el estado de la aplicación. La persistencia en localStorage está preparada para implementarse cuando sea necesario.
